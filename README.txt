TREINTELLINGEN PWA

Bestanden:

- manifest.webmanifest
- service-worker.js
- icons/

Belangrijk:
Een PWA werkt niet volledig door index.html rechtstreeks als lokaal bestand te openen.
Plaats de volledige map op een website met HTTPS, bijvoorbeeld GitHub Pages, Netlify of je eigen hosting.
Open daarna de website in Chrome op Android en kies 'App installeren' of 'Toevoegen aan startscherm'.

De tellingen worden automatisch na iedere invoer in localStorage opgeslagen.
De knop 'Einde dag' wist de opgeslagen tellingen na bevestiging.
